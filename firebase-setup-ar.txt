لوحة إدارة منتجات الدولي

بعد اكتمال الربط الأولي، لا تحتاج إلى فتح GitHub لإضافة المنتجات أو تعديلها.

1. افتح https://aldawly-tools.github.io/aldawly-website/admin.html
2. اضغط «دخول بحساب Google» واستخدم حساب الإدارة المصرّح به.
3. أضف اسم المنتج والماركة والقسم والسعر والوصف، واختر صورة من جهازك أو أضف رابطها.
4. اضغط «حفظ المنتج». سيظهر للزوار بعد تحديث صفحة المتجر.

يمكن تعديل المنتجات أو حذفها من قائمة المنتجات الحالية، كما يمكن استيراد أو تنزيل ملف products.js عند الحاجة. استيراد الملف يضيف أو يحدّث المنتجات المطابقة لأرقامها ولا يحذف المنتجات الأخرى. صور الجهاز تُصغّر وتُحفظ منفصلة في قاعدة المتجر؛ تنزيل products.js يحفظ بيانات المنتجات ولا ينسخ صور قاعدة البيانات.

إذا لم تستطع الحفظ، تأكد من الدخول بحساب الإدارة نفسه. لا تشارك كلمة مرور Google أو تضعها في أي ملف. قواعد قاعدة البيانات تمنح القراءة للزوار وتسمح بالكتابة لحساب الإدارة فقط.


إدارة طلبات العملاء

تمت إضافة قسم «طلبات العملاء» إلى لوحة الإدارة. لكي تُسجّل الطلبات في Firestore، أضف صلاحية إنشاء الطلبات للزوار مع إبقاء القراءة والتعديل لحساب الإدارة فقط.

في Firebase Console افتح Firestore Database > Rules. داخل كتلة match /databases/{database}/documents أضف الدالة والقاعدة التالية إلى قواعدك الحالية، ولا تستبدل قواعد المنتجات الموجودة. استبدل البريد ببريد حساب Google الذي تستخدمه لدخول لوحة الإدارة:

function isStoreAdmin() {
  return request.auth != null && request.auth.token.email == "ضع-بريد-الإدارة-هنا";
}
match /orders/{orderId} {
  allow create: if request.resource.data.keys().hasAll(["orderNumber","customerName","customerPhone","customerAddress","notes","items","totalText","status","source","createdAt"])
    && request.resource.data.status == "new"
    && request.resource.data.source == "website"
    && request.resource.data.customerName is string
    && request.resource.data.customerName.size() > 0
    && request.resource.data.customerName.size() <= 80
    && request.resource.data.customerPhone is string
    && request.resource.data.customerPhone.size() >= 8
    && request.resource.data.customerPhone.size() <= 15
    && request.resource.data.customerAddress is string
    && request.resource.data.customerAddress.size() > 0
    && request.resource.data.customerAddress.size() <= 300
    && request.resource.data.items is list
    && request.resource.data.items.size() > 0
    && request.resource.data.items.size() <= 50;
  allow read, update, delete: if isStoreAdmin();
}

بعد إضافة القاعدة اضغط Publish. الطلبات تحتوي بيانات شخصية (اسم وهاتف وعنوان)، لذلك لا تسمح للزوار بقراءتها أو تعديلها. جرّب طلبًا واحدًا ثم راجعه في لوحة الإدارة.
