# Dawly Stock

نسخة أولية مستقلة لإدارة مخزن الدولي، موجودة في المسار `/stock/`.

## الوظائف الحالية
- إدارة الأصناف والأكواد والكميات وأسعار الشراء والبيع وحد التنبيه.
- وارد ومنصرف وتسوية جرد مع سجل حركات.
- سجل العملاء والموردين.
- تقرير تقييم المخزون.
- استيراد وتصدير CSV ونسخ احتياطي JSON واستعادة.

## ملاحظة مهمة عن حفظ البيانات
هذه النسخة الأولى تحفظ البيانات محليًا في المتصفح على الجهاز الحالي باستخدام localStorage. لذلك لا تعتبر المزامنة بين الأجهزة أو النسخ السحابي مفعّلين بعد. لا تستخدمها كقاعدة بيانات تشغيلية متعددة الأجهزة قبل إكمال ربط Firebase Authentication وCloud Firestore واختبار قواعد الأمان.

## الخطوة المطلوبة لتفعيل السحابة
1. إنشاء مشروع Firebase منفصل خاص بالمخازن (لا تستخدم قاعدة بيانات متجر البيع).
2. تفعيل Email/Password Authentication وإنشاء حساب المدير يدويًا.
3. إنشاء Cloud Firestore.
4. إضافة إعدادات Firebase العامة للتطبيق، ثم كتابة قواعد Firestore بحيث لا يستطيع القراءة أو الكتابة إلا المستخدمون المصرح لهم.
5. اختبار تسجيل الدخول والمزامنة من جهازين، ثم اختبار النسخ الاحتياطي والاستعادة.

لا تضع كلمات المرور أو مفاتيح الخدمة الخاصة (service account) في ملفات الواجهة أو المستودع العام.

## النشر
إذا كان Cloudflare Pages ينشر المستودع من الفرع الرئيسي تلقائيًا، يصبح التطبيق متاحًا على `https://aldawly-website.pages.dev/stock/` بعد اكتمال عملية النشر. يجب التأكد من نجاح آخر عملية نشر قبل الاعتماد على الرابط.
